# 학생 안내

1. ID·비밀번호·이름·학번·별명으로 가입합니다. 이메일은 필요하지 않습니다.
2. 대회 소개에서 교수자가 전달한 초대 코드를 입력합니다. 승인 후 데이터·순위·제출을 이용할 수 있습니다.
3. 문제의 예측 대상, 단위·변환, 데이터 출처, 분할 방법과 지표를 읽습니다. `train.csv`에는 정답이 있으며 `val.csv`·`test.csv`에는 없습니다.
4. `sample_submission.csv`의 `prediction` 열을 채웁니다. val·test 전체 ID가 필요합니다. ID는 문자열이며 앞자리 0을 유지하세요. 행 순서는 자유입니다.
5. `sample_id,prediction` 두 열의 UTF-8 CSV를 제출합니다. 파일 한도는 10MB입니다. 분류는 양성 클래스 확률 0~1, 회귀는 지정된 단위로 제출합니다.
6. 내 제출에서 채점 결과를 확인합니다. 진행 중 순위는 문제별 최고 val 점수입니다.
7. 마감 전 채점 완료 제출 중 문제별 하나를 최종 지정합니다. 미지정이면 최고 val 제출을 자동 선택합니다. 마감 전 접수된 작업은 마감 후에도 채점합니다.
8. 관리자가 결과를 공개하면 선택된 제출의 test 점수와 최종 순위를 확인합니다. test 정답은 공개하지 않습니다.

모든 시각은 한국 시간입니다. 마감은 파일 전체가 서버에 도착한 시각입니다. 업로드는 마감보다 충분히 일찍 완료하세요. 일일 제한은 기본 문제별 5회이며 채점 대기 제출도 포함합니다. 형식 오류·서버 오류는 횟수에서 제외됩니다. 같은 요청을 재전송하면 중복으로 접수하지 않습니다.

순위는 반올림 전 점수로 비교하고 같으면 먼저 접수된 제출을 우선합니다. 순위표의 6자리 표시는 편의를 위한 반올림입니다.

공개 이름은 기본 별명입니다. 내 프로필에서 실명 표시로 바꿀 수 있습니다. 이름·학번 대응 정보는 관리자만 봅니다. 같은 대회에서 같은 학번의 중복 참가는 차단됩니다.

비밀번호를 잊으면 교수자에게 수업 연락 수단으로 본인 확인을 요청하세요. 교수자가 발급한 코드를 계정 복구 화면에 입력하고 새 비밀번호를 설정합니다. 코드는 30분 동안 한 번만 유효하며 복구하면 기존 로그인 세션이 모두 해제됩니다.
